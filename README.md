# Basic Testing – Выполненный проект

✅ Это моя завершённая реализация проекта [basic-testing](https://github.com/AlreadyBored/basic-testing).
В рамках задания я написал модульные тесты для различных сценариев, включая синхронный и асинхронный код, классы, а также тестирование с моками и снапшотами.

---

### Как запустить проект

1. Убедитесь, что установлен [Node.js](https://nodejs.org/en/download/) версии 22.x.x (рекомендуется 22.14.0 или выше).
2. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/falkonpawl/basic-testing.git
   ```
3. Перейдите в папку проекта:

   ```bash
   cd basic-testing
   ```
4. Установите зависимости:

   ```bash
   npm install
   ```
5. Запустите тесты:

   ```bash
   npm run test         # обычный режим
   npm run test:verbose # подробный вывод
   ```

### Что реализовано

#### ✅ Простые тесты

Тестирование функции `simpleCalculator`, реализующей базовые математические операции.
Проверяются корректные вычисления и возвращение `null` при недопустимом вводе.
Файл: `src/01-simple-tests/index.test.ts`

---

#### ✅ Табличные тесты

Те же проверки, что и в простых тестах, но выполнены в формате **табличных тестов** (table-driven testing) с использованием `test.each` из Jest.
Файл: `src/02-table-tests/index.test.ts`

---

#### ✅ Обработка ошибок и асинхронность

Проверка асинхронных функций, включая выбрасывание и перехват исключений, а также отклонённые промисы.
Файл: `src/03-error-handling-async/index.test.ts`

---

#### ✅ Тестирование класса

Тесты для класса банковского счёта, включающего синхронные и асинхронные методы, а также внутренние вызовы других методов.
Файл: `src/04-test-class/index.test.ts`

---

#### ✅ Частичное мокирование

Применение частичного мокирования (partial mocking) с использованием Jest для отдельных функций модуля.
Файл: `src/05-partial-mocking/index.test.ts`

---

#### ✅ Мокирование API Node.js

Тестирование работы с Node.js API — `fs`, `setTimeout`, `setInterval` — с использованием моков, без взаимодействия с реальной файловой системой и временем.
Файл: `src/06-mocking-node-api/index.test.ts`
